## 1 `docker/code-sandbox/ast_guard.py`

常量（供测试直接引用）：

```python
MAX_SOURCE_BYTES = 8192
MAX_AST_NODES = 2000
MAX_DEPTH = 3
MAX_INPUT_BYTES = 1_048_576      # 1 MB
MAX_INPUT_ROWS = 5000
MAX_OUTPUT_BYTES = 65536         # 64 KB
ALLOWED_CALLS = frozenset({"len","sum","min","max","abs","round","sorted","enumerate",
                           "range","zip","str","int","float","list","dict","set","tuple",
                           "bool","print","datetime"})
FORBIDDEN_NODE_TYPES: dict[str, str]   # AST 节点名 → 规则号
FORBIDDEN_NAMES: frozenset[str]
FORBIDDEN_ATTRS: frozenset[str]
```

`FORBIDDEN_NODE_TYPES` 规则号（固定，测试断言用）：

| 节点 | 规则号 |
| --- | --- |
| `Import` | `R10_IMPORT` |
| `ImportFrom` | `R11_IMPORT_FROM` |
| `Global` | `R12_GLOBAL` |
| `Nonlocal` | `R13_NONLOCAL` |
| `ClassDef` | `R14_CLASS` |
| `AsyncFunctionDef` | `R15_ASYNC_DEF` |
| `With` / `AsyncWith` | `R16_WITH` |
| `Try` / `TryStar` | `R17_TRY` |
| `Lambda` | `R18_LAMBDA` |
| `Raise` | `R19_RAISE` |
| `Delete` | `R20_DELETE` |
| `Await` / `AsyncFor` | `R21_AWAIT` |
| `Match` | `R22_MATCH` |
| `Yield` / `YieldFrom` | `R23_YIELD` |

其它规则号：`R00_SYNTAX`（语法错）、`R01_EMPTY`（空源码）、`R02_TOO_LARGE`（>8KB）、
`R03_TOO_MANY_NODES`（AST 节点 >2000）、`R04_TOO_DEEP`（嵌套 >3）、
`R05_FORBIDDEN_NAME`（禁用名）、`R06_FORBIDDEN_ATTR`（禁用属性）、
`R07_CALL_NOT_ALLOWED`（调用不在白名单）、`R08_FORBIDDEN_EXPR`（其它禁用语法）、
`R30_INPUT_TOO_LARGE`、`R31_INPUT_TOO_MANY_ROWS`、`R32_INPUT_NOT_JSON`。

`FORBIDDEN_NAMES`（文档基线 + 逃逸补强）：
`open exec eval compile __import__ getattr setattr globals locals vars input exit breakpoint type
__build_class__ super object memoryview dir help quit id issubclass hasattr delattr
__loader__ __spec__ breakpoint __debug__`

`FORBIDDEN_ATTRS`（文档基线 + 逃逸补强）：
`__class__ __bases__ __subclasses__ __globals__ __code__ __builtins__ mro format
__dict__ __mro__ __getattribute__ __getattr__ __setattr__ __delattr__ __reduce__ __reduce_ex__
__init_subclass__ __subclasshook__ __closure__ __defaults__ __kwdefaults__ __traceback__
__self__ __func__ __globals__ __annotations__ __module__`

API：

```python
class AstRejection(Exception):
    def __init__(self, rule: str, reason: str) -> None: ...
    # 属性：.rule: str  .reason: str
    def to_dict(self) -> dict[str, str]:   # {"rule": ..., "reason": ...}

def check_source(code: str) -> dict[str, object]:
    """通过返回 ast_summary；不通过抛 AstRejection。
    ast_summary 键：nodes, depth, lines, bytes, calls(list[str] 去重排序),
    names(list[str] 去重排序), rule_count(int = 0)
    """

def check_inputs(inputs: object) -> dict[str, int]:
    """返回 {"rows": int, "bytes": int}；超限抛 AstRejection。"""
```

嵌套深度定义：`Module` 计 0；每条**语句块**（函数体、`if/elif/else` 体、`for/while` 体）进入 +1；
表达式不计入。深度 > `MAX_DEPTH` 抛 `R04_TOO_DEEP`。

`check_source` 必须先按字节长度检 `R02_TOO_LARGE`，再 `ast.parse`（`SyntaxError` → `R00_SYNTAX`），
再逐节点走 `ast.walk`；命中多个规则时按 `ast.walk` 顺序取**第一个**。

## 2 `docker/code-sandbox/runner.py`

```python
RESULT_VAR = "result"
DEFAULT_LIMITS = {"wall_ms": 5000, "mem_mb": 256, "output_bytes": 65536}

def normalize_limits(limits: dict | None) -> dict   # 缺省补默认，越界截到上限

def execute(code: str, inputs=None, limits: dict | None = None) -> dict
```

`execute` 返回**固定键集**：

```python
{
  "status": "ok" | "rejected" | "timeout" | "error",
  "result": <JSON 可序列化对象> | None,
  "stdout": str,                      # 已截断到 output_bytes
  "truncated": bool,
  "ast_summary": dict | None,         # rejected 时为 None
  "metrics": {"wall_ms": int, "cpu_ms": int, "peak_mem_kb": int},
  "error_code": None | "VALIDATION_001" | "UNKNOWN_RESULT_001" | "INTERNAL_001",
  "detail": str,
}
```

状态映射（固定）：

| 情形 | status | error_code | detail |
| --- | --- | --- | --- |
| 通过并成功 | `ok` | `None` | `""` |
| AST/输入被拒 | `rejected` | `VALIDATION_001` | `"<规则号>: <原因>"` |
| 墙钟超时（父进程 kill） | `timeout` | `UNKNOWN_RESULT_001` | `"超时 <wall_ms>ms，进程已终止"` |
| 内存超限（子进程被杀/ MemoryError） | `error` | `INTERNAL_001` | `"内存超限（<mem_mb>MB）"` |
| 用户代码抛异常 | `error` | `INTERNAL_001` | `"<异常类型>: <异常信息>"`（不泄栈） |
| `result` 不可 JSON 序列化 | `error` | `INTERNAL_001` | `"结果不可 JSON 序列化"` |

执行模型（跨平台可测）：

- 父进程用 `subprocess` 重新执行本文件（`sys.executable runner.py --report <临时文件>`），
  把 payload（`{"code","inputs","limits"}`）写到子进程 stdin。
- 父进程 `communicate(timeout=wall_ms/1000)`；`TimeoutExpired` → `kill()` → status `timeout`。
- 子进程套 rlimit（`resource` 可用时）：`CPU=5`、`AS=mem_mb*1MB`、`FSIZE=65536`、`NOFILE=32`、`NPROC=1`；
  不可用（Windows）时跳过，仅靠父进程墙钟。
- 子进程把用户代码放在独立命名空间执行：
  `{"__name__": "__sandbox__", "inputs": inputs, "data": inputs, "result": None, "datetime": datetime}`
  （`datetime` 为 `datetime.datetime` 的受限代理：仅暴露 `datetime`、`date`、`timedelta`）。
- 用户 `print` 重定向到 `io.StringIO`，超 `output_bytes` 置截断标记并停止累积。
- 报告 JSON 由子进程写入 `--report` 文件（避免与用户 stdout 混流）；父进程读取。
- `metrics.peak_mem_kb` 取 `resource.getrusage(RUSAGE_SELF).ru_maxrss`（Linux 已是 KB；
  达尔文需 /1024）；不可用时 `0`。`cpu_ms` 取 `ru_utime + ru_stime`；`wall_ms` 由父进程计时。

## 3 `docker/code-sandbox/app.py`（FastAPI，uvicorn `app:app`）

```python
PURPOSES = ("custom_stats", "budget_split", "fee_simulation")

@app.get("/health")        -> {"status": "ok"}
@app.get("/selfcheck")     -> {"network": bool, "credentials": int, "mounts": [str, ...]}
@app.post("/run")          -> 见下
```

`/selfcheck` 在启动时采样并缓存：`network` = 能否建立外部 TCP（期望 `False`）；
`credentials` = 环境变量个数（期望 `0`，容器 `environment: []`）；
`mounts` = `/proc/mounts` 中除 `/`、`/tmp` 之外的挂载点（期望 `[]`；无 `/proc` 时 `[]`）。

`POST /run` 请求体（Pydantic）：

```python
class Limits(BaseModel):
    wall_ms: int = 5000
    mem_mb: int = 256
    output_bytes: int = 65536

class RunRequest(BaseModel):
    code: str
    purpose: str = "custom_stats"
    inputs: Any | None = None          # dict 或 list
    limits: Limits | None = None
    idempotency_key: str | None = None
```

响应体（固定键集，与 `runner.execute` 合并）：

```python
{
  "status": ..., "result": ..., "stdout": ..., "truncated": ...,
  "ast_summary": ..., "metrics": {...}, "error_code": ..., "detail": ...,
  "purpose": str,
  "idempotency_key": str,            # 缺省时服务端生成 uuid4().hex
  "sandbox": {"image": str, "network": bool, "credentials": int},
}
```

- `purpose` 不在 `PURPOSES` → `status="rejected"`、`error_code="VALIDATION_001"`、`detail="R40_PURPOSE: 未知用途"`。
- `code` 字节数 > 8192 → `rejected` / `VALIDATION_001` / `detail="R02_TOO_LARGE: ..."`。
- `limits` 越界截到上限（`wall_ms<=5000`、`mem_mb<=256`、`output_bytes<=65536`）。
- 幂等：同 `idempotency_key` 重复请求返回首次结果（进程内 LRU，上限 256 条）。
- 同步执行放线程：`await asyncio.to_thread(runner.execute, code, inputs, limits)`。
- `sandbox.image` 取 `os.environ.get("SANDBOX_IMAGE", "bank-agent/code-sandbox:0.1.0")`。

## 6 `Struct_of_Agent/common/code_compute.py`

```python
PURPOSES = ("custom_stats", "budget_split", "fee_simulation")
DEGRADED_MESSAGE = "自定义统计暂不可用，已切换标准统计"
DEFAULT_BASE_URL = "http://code-sandbox:8022"
SANDBOX_LABEL = "沙箱计算"
STANDARD_LABEL = "标准统计"

class CodeComputeUnavailable(RuntimeError):
    def __init__(self, detail: str = DEGRADED_MESSAGE, *, reason: str = "unavailable",
                 error_code: str = "NOT_READY_001") -> None: ...
    # 属性：.detail(str 展示用) .reason(str) .error_code(str) .payload -> dict

def make_idempotency_key() -> str            # uuid4().hex
def normalize_limits(limits: dict | None) -> dict[str, int]

class CodeComputeAdapter(Protocol):
    name: str
    def available(self) -> bool: ...
    def selfcheck(self) -> dict           # {"network": bool|None, "credentials": int|None, "mounts": list|None}
    def run(self, *, code: str, purpose: str = "custom_stats", inputs=None,
            limits: dict | None = None, idempotency_key: str | None = None) -> dict

class HttpCodeComputeAdapter:      # name = "http"
    def __init__(self, base_url: str | None = None, *, timeout_s: float = 8.0) -> None: ...

class DisabledCodeComputeAdapter:  # name = "disabled"
    # available() -> False；run() 抛 CodeComputeUnavailable(DEGRADED_MESSAGE, reason="disabled")

def get_adapter() -> CodeComputeAdapter
def configure_adapter(adapter: CodeComputeAdapter | None) -> None
def reset_adapter() -> None
def code_compute_enabled() -> bool

def guarded_run(*, code: str, purpose: str = "custom_stats", inputs=None,
                limits: dict | None = None, tenant_id=None, user_id=None) -> dict
def compute_category_monthly(inputs: dict, *, tenant_id=None, user_id=None) -> dict
```

`guarded_run` 语义（顺序固定）：

1. `circuit_breaker.require_closed(tenant_id=..., user_id=..., capability=circuit_breaker.CAP_CODE_COMPUTE)`
   → 捕获 `CircuitOpenError` → 抛 `CodeComputeUnavailable("代码计算能力已熔断，暂时不可用", reason="circuit_open", error_code="NOT_READY_001")`。
2. 取适配器；`available()` 为假 → 抛 `CodeComputeUnavailable(DEGRADED_MESSAGE, reason="disabled")`。
3. `adapter.run(...)`；`status=="ok"` → `circuit_breaker.record_success(...)`，否则 `record_failure(...)`；
   返回沙箱响应 dict，并追加 `{"sandbox_label": SANDBOX_LABEL}`。
4. 传输异常 `CodeComputeUnavailable` 原样上抛（**绝不在本地重算冒充沙箱结果**）。

`HttpCodeComputeAdapter` 细节：环境变量 `BANK_AGENT_CODE_SANDBOX_URL`（缺省 `DEFAULT_BASE_URL`）；
`BANK_AGENT_CODE_COMPUTE_MODE` ∈ `auto|http|disabled`（缺省 `auto`）；`httpx.Client`，
`POST {base}/run`、`GET {base}/selfcheck`；连接/超时 → `CodeComputeUnavailable("代码沙箱不可达，已切换标准统计", reason="transport")`；
HTTP 5xx → `reason="upstream_error"`。

`compute_category_monthly(inputs, ...)`：`inputs = {"records": [{"category": str, "month": "YYYY-MM", "amount_fen": int}, ...]}`，
生成沙箱代码（按 `category` 分组，算每月均值与全期均值，`amount_fen` 整数运算），返回
`{"ok": True|False, "label": "沙箱计算"|"标准统计", "degraded": bool, "message": str,
  "result": {...}|None, "sandbox": {...}|None, "error_code": str|None}`；
降级时 `label="标准统计"`、`degraded=True`、`message=DEGRADED_MESSAGE`、`result=None`。
